# Rebuilding the selected designs

## What is included

`final_designs/` is the self-contained design package. The regular cell and each selected taper assembly include:

- `project.sonx`: complete native Sonnet project, including materials, stack, mesh, ports, reference planes, sweep, and control settings.
- `layout.gds`: exact approved native metal in bottom-left box coordinates, on the 2 um grid.
- `parameters.json`, `design.json`, and original selection/provenance where applicable.
- `response.snp` and `fit.json` where a completed saved response exists, plus the S21 plot.
- `calibration/`: available calibration projects, exported responses, and summaries needed to inspect or rerun the selected calibration.
- `rebuild_validation.json`: completed geometry/import/read checks; this is not an EM result.

The original reference drawing is `reference_taper_geometry.png` at the repository root. The full-filter folder contains its native input and layout; the running full sweep has not been promoted to a completed response.

## Verify without Sonnet

From the repository root:

```powershell
uv sync --locked
uv run python tools/check_published_files.py
uv run python -m geometry.rebuild_final --verify-only
```

This checks the package hashes, native/GDS metal equality, 2 um grid, two 50 ohm ports, mesh dimensions, and the reconstructed full-filter layout.

## Regenerate native projects

```powershell
uv run python -m geometry.rebuild_final --output-dir build/final_designs
```

If Sonnet is elsewhere:

```powershell
uv run python -m geometry.rebuild_final --sonnet-bin 'C:\path\to\Sonnet\bin'
```

The tool reimports each approved layout through Sonnet's GDS translator, reattaches its port edges, preserves material/stack/solver settings and reference planes, and asks `soncmd` to read the result. The projects and logs appear only under the chosen build directory. It does not start `em.exe` or reuse a cache from the development machine.

The full-filter metal is regenerated by clipping the current taper assembly, repeating the regular-cell body ten times, and mirroring the three tapers on the right. Its metal must exactly match the checked-in full-filter input. Individual staged taper projects replay the approved frozen GDS layouts; this is not a claim that every historical parameter-search script is portable or that arbitrary changed settings are automatically validated. Their source and original parameter/provenance records are included for future development.

The six packaged projects were reimported and read successfully with Sonnet 19.52.2025.261. GDS/native XOR checks passed. No new EM solve was performed for these packaging checks.

## Run a new EM calculation

Open the rebuilt `project.sonx` in Sonnet, inspect its settings, and start analysis when intended. A working Sonnet license is required. Completed `.snp` exports are ordinary saved S-parameter results; `sondata` is Sonnet's calculation cache. It can be regenerated and is deliberately excluded from Git. A fresh simulation may take substantial time because the development machine's cache is not published.

Calibration projects are separate native inputs under each design's `calibration/` folder. Preserve their intended added capacitors and frequency coverage when rerunning. Original calibration/provenance summaries retain old absolute paths as historical evidence; the included files are reached through their relative design-folder locations, not through those old paths.
